### Переменные и значения

#### `val` (неизменяемое) и `var` (изменяемое)
- **`val`** — определяет неизменяемую переменную (константу). После инициализации значение изменить нельзя.  
- **`var`** — определяет изменяемую переменную, значение можно переприсвоить.

В Scala рекомендуется всегда использовать `val`, если явно не требуется изменение значения. Это способствует функциональному стилю и безопасному коду.

```scala
val name = "Alice"
// name = "Bob"  // ошибка компиляции: reassignment to val

var count = 0
count = 1        // ok
```

#### Вывод типов (type inference)
Scala способна автоматически выводить тип переменной по правой части выражения. Аннотацию типа можно опускать.

```scala
val message = "Hello"        // String
val numbers = List(1, 2, 3)  // List[Int]
```

При необходимости тип можно указать явно (это часто улучшает читаемость и может потребоваться для разрешения перегрузок):

```scala
val age: Int = 25
val ratio: Double = 0.5
```

#### Ленивая инициализация (`lazy val`)
Переменная, объявленная как `lazy val`, вычисляется только при первом обращении к ней. Полезно для дорогих вычислений, которые могут не понадобиться, или для разрешения циклических зависимостей при инициализации.

```scala
lazy val heavyData: String = {
  println("Вычисляю...")
  "результат"
}

println("До обращения")
println(heavyData) // здесь инициализация
println(heavyData) // повторно не вычисляется
```
Вывод:
```
До обращения
Вычисляю...
результат
результат
```

#### Объявление типа
Тип записывается после двоеточия. Это общий принцип для `val`, `var`, параметров методов, возвращаемых значений.

```scala
val items: List[String] = List("a", "b")
```

### Базовые типы данных

#### Числовые типы: Int, Long, Double, Float, Short, Byte, Char
Все числовые типы в Scala — объекты, но компилируются в примитивы JVM (благодаря value-классам).  
- `Byte`, `Short`, `Int`, `Long` — целые числа (8, 16, 32, 64 бита).  
- `Float`, `Double` — числа с плавающей точкой (32 и 64 бита).  
- `Char` — символ Unicode (16 бит).

```scala
val i: Int = 42
val l: Long = 10000000000L
val d: Double = 3.14
val f: Float = 2.7f
val c: Char = 'A'
```

Литералы целых чисел могут записываться в десятичной, шестнадцатеричной или двоичной системах:
```scala
val hex = 0xFF        // 255
val bin = 0b1010      // 10
```

#### Boolean
Тип с двумя значениями `true` и `false`. Поддерживает обычные логические операции: `&&`, `||`, `!`.

```scala
val flag: Boolean = true
val result = !flag || false
```

#### Строки: String, интерполяция (s, f, raw), многострочные строки
Строковые литералы в двойных кавычках — это объекты класса `java.lang.String`.

```scala
val greeting = "Hello"
```

**Строковая интерполяция:**
- `s"..."` — подстановка выражений через `$` или `${}`.
  ```scala
  val name = "Мир"
  val s = s"Привет, $name! Длина: ${name.length}"
  // Привет, Мир! Длина: 3
  ```
- `f"..."` — форматирование, как `printf`.
  ```scala
  val height = 1.75
  val f = f"Рост: $height%.2f метра"
  // Рост: 1,75 метра
  ```
- `raw"..."` — не обрабатывает escape-последовательности (кроме `$`).
  ```scala
  val raw = raw"Перенос строки: \n не сработает"
  // Перенос строки: \n не сработает
  ```

**Многострочные строки** заключаются в тройные кавычки `"""..."""`. Внутри можно сохранять любые символы, включая кавычки и переносы строк. Для управления отступами используйте метод `stripMargin` (по умолчанию разделитель — `|`).

```scala
val multiline =
  """|Первая строка
     |Вторая строка
     |Третья строка""".stripMargin
```

#### Unit, Null, Nothing, Any, AnyVal, AnyRef
Иерархия типов Scala (упрощённо):
```
          Any
         /   \
    AnyVal    AnyRef (java.lang.Object)
   /      \
Unit      Int, Double, ...
          (value-классы)
```
- **Any** — вершина иерархии, супертип всех типов.
- **AnyVal** — базовый тип для всех value-типов (Int, Double, Char, Unit и т.д.). Они представлены как примитивы JVM.
- **AnyRef** — соответствует `java.lang.Object`, супертип всех ссылочных типов (строки, списки, пользовательские классы).
- **Unit** — аналог `void` в Java, тип, имеющий единственное значение `()`. Функции, возвращающие `Unit`, обычно вызываются ради побочных эффектов.
- **Null** — тип, единственное значение `null`. Является подтипом всех AnyRef-типов. На практике стараются избегать `null` и использовать `Option`.
- **Nothing** — нижний тип, подтип всех типов. Не имеет значений. Используется для обозначения невозвратных функций (бросающих исключения, бесконечных циклов) и в коллекциях (например, `Nil` имеет тип `List[Nothing]`).

```scala
val unitVal: Unit = ()
def printMessage(msg: String): Unit = println(msg)

val nothingList = Nil    // List[Nothing]
def fail(): Nothing = throw new Exception("Ошибка")
```

### Операции и выражения

#### Арифметические, логические, побитовые операторы
Арифметические: `+`, `-`, `*`, `/`, `%` (остаток от деления). Работают так же, как в Java/C.  
Логические: `&&` (и), `||` (или), `!` (не). Применяются к `Boolean`.  
Побитовые: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`. Применяются к целочисленным типам.

В Scala операторы на самом деле являются методами объектов. `a + b` эквивалентно `a.+(b)`.  
Благодаря этому можно создавать собственные операторы (например, для матриц) и использовать инфиксную нотацию.

```scala
val x = 10 + 5
val y = 10.+(5)   // то же самое

val a = true && false
val bitwiseAnd = 0x0F & 0xF0   // 0
```

#### Приоритет операторов
Приоритет определяется первым символом оператора, кроме случаев, когда оператор заканчивается на `=`. Самый низкий приоритет у буквенных операторов, затем `|`, `^`, `&`, `=!`, `< >`, `:`, `+ -`, `* / %`, и самый высокий у всех остальных специальных символов.  
Постфиксные операторы (вызываемые без точки) требуют импорта `scala.language.postfixOps` (или включения флага) в Scala 2, а в Scala 3 они полностью запрещены без явного синтаксиса.

Для избежания путаницы лучше использовать скобки, если выражение неочевидно.

#### Выражения против инструкций (всё возвращает значение)
В Scala практически все конструкции являются выражениями, т.е. возвращают значение. Даже присваивание (`a = b`) возвращает `Unit`, но в целом это позволяет использовать `if`, `match`, `try` как выражения.

```scala
val max = if (a > b) a else b    // выражение if возвращает значение
```

Исключение — циклы `while` и `do-while`, которые возвращают `Unit` (не используются как выражения для получения значений). В функциональном программировании циклы обычно заменяются вызовами высшего порядка (`map`, `filter` и т.д.).

### Управляющие конструкции

#### `if`/`else` как выражение
`if` всегда возвращает значение. Если ветка `else` отсутствует, то тип результата — `AnyVal`/`Any` (в зависимости от веток), потому что подразумевается `else ()`. На практике всегда пишите `else`.

```scala
val score = 85
val grade = if (score > 90) "A"
            else if (score > 75) "B"
            else "C"

// тип автоматически выведен как String
```

#### Циклы: `while`, `do-while`
Циклы есть, но они не идиоматичны в чистом Scala-коде. Возвращают `Unit`.

```scala
var i = 0
while (i < 5) {
  println(i)
  i += 1
}

var j = 0
do {
  println(j)
  j += 1
} while (j < 5)
```

#### `for`-генераторы (for-comprehensions) — базовое использование (map, flatMap)
For-генераторы (for-comprehensions) — синтаксический сахар над методами `map`, `flatMap`, `foreach` и `withFilter`. Позволяет элегантно работать с коллекциями, `Option`, `Future` и другими типами, поддерживающими эти методы.

```scala
val numbers = List(1, 2, 3, 4)
val doubled = for n <- numbers yield n * 2
// эквивалентно: numbers.map(n => n * 2)
```

Если `yield` не указан, то for работает как цикл `foreach`, возвращая `Unit`:
```scala
for n <- numbers do println(n)
```

Можно использовать несколько генераторов (декартово произведение или flatMap):
```scala
val pairs = for {
  x <- List(1, 2)
  y <- List('a', 'b')
} yield (x, y)
// List((1,a), (1,b), (2,a), (2,b))
// эквивалентно: List(1,2).flatMap(x => List('a','b').map(y => (x,y)))
```

#### `for` с условиями (`if`)
В for-генераторах можно добавлять фильтры (guard) с помощью `if`:

```scala
val evens = for n <- numbers if n % 2 == 0 yield n
// эквивалентно: numbers.withFilter(n => n % 2 == 0).map(n => n)
```

В Scala 3 синтаксис `for` может использовать фигурные скобки и ключевое слово `do` или `yield`:
```scala
val evens = for
  n <- numbers
  if n % 2 == 0
yield n
```

### Pattern matching (сопоставление с образцом)

Pattern matching — мощный механизм, заменяющий цепочки `if-else` и операторы `switch` из Java.

#### Синтаксис `match`/`case`
Выражение `match` работает с переменной и набором альтернатив:

```scala
val dayOfWeek = "Monday"
val activity = dayOfWeek match
  case "Saturday" | "Sunday" => "Отдых"
  case "Monday" => "Начало недели"
  case other => s"Рабочий день: $other"
```

#### Паттерны: константы, переменные, wildcard (`_`)
- **Константы**: литералы или `val`-идентификаторы с большой буквы (стабильные идентификаторы) — точное совпадение.
- **Переменные**: идентификатор с маленькой буквы — захватывает любое значение и связывает его с именем.
- **Wildcard `_`**: соответствует чему угодно и не связывает значение.
```scala
x match
  case 0 => "ноль"            // константа
  case name => s"Привет, $name"  // переменная (ловушка: может перехватить всё)
  case _ => "всё остальное"
```

Внимание: переменная с маленькой буквы создаёт новую переменную, а не ссылается на существующую. Чтобы сослаться на существующий `val`, используйте обратные кавычки (`` ` ``) в Scala 2, или объявите его с заглавной буквы. В Scala 3 можно использовать `val pi = 3.14` и затем в паттерне `` case `pi` => ``.

#### Охранники (`if`)
Можно добавить условие после паттерна с помощью `if`:

```scala
val num = 15
val desc = num match
  case n if n < 0 => "отрицательное"
  case n if n == 0 => "ноль"
  case n if n > 0 => "положительное"
```

#### Сопоставление типов, извлечение из case-классов
Можно проверять тип значения и одновременно извлекать поля:
```scala
sealed trait Shape
case class Circle(radius: Double) extends Shape
case class Rectangle(width: Double, height: Double) extends Shape

def area(s: Shape): Double = s match
  case Circle(r) => Math.PI * r * r
  case Rectangle(w, h) => w * h
```
Паттерн-матчинг с извлечением возможен благодаря тому, что case-классы автоматически имеют метод `unapply`, используемый компилятором.

Можно также просто проверить тип:
```scala
def describe(x: Any): String = x match
  case i: Int => s"Целое $i"
  case s: String => s"Строка $s"
  case _ => "что-то ещё"
```

### Функции (введение)

#### Объявление функции (`def`)
Ключевое слово `def` определяет метод (функцию, привязанную к объекту/классу или на верхнем уровне). Базовая структура:
```scala
def functionName(param1: Type1, param2: Type2): ReturnType = {
  // тело
}
```

#### Параметры и аргументы
Параметры указываются в круглых скобках через запятую, имя: тип. Вызов функции может использовать позиционные или именованные аргументы.

```scala
def greet(name: String, age: Int): String =
  s"Привет, $name! Тебе $age лет."

greet("Анна", 25)               // позиционные
greet(age = 30, name = "Пётр") // именованные
```

#### Возвращаемый тип и автоматический вывод
Тип возвращаемого значения можно опустить, если он выводится компилятором. Однако для публичных методов в API рекомендуется указывать явно. Для рекурсивных функций аннотация типа обязательна.

```scala
def add(x: Int, y: Int) = x + y  // Int выведен

def factorial(n: Int): BigInt =
  if n <= 1 then 1 else n * factorial(n - 1)
```

#### Процедурный синтаксис (Unit)
Если функция не возвращает значимого результата, тип возврата — `Unit`. Можно не писать `=`, а использовать фигурные скобки (процедурный синтаксис, считается устаревшим в Scala 2, не рекомендуется). Лучше всегда использовать `=` и явно указывать `Unit` или полагаться на вывод.

```scala
def printSum(a: Int, b: Int): Unit = {
  println(a + b)
}
```
В Scala 3 рекомендуется единообразие:
```scala
def printSum(a: Int, b: Int): Unit = println(a + b)
```

#### Аргументы по умолчанию и именованные аргументы
Можно задать значение по умолчанию для параметров:
```scala
def connect(host: String = "localhost", port: Int = 8080): Unit =
  println(s"Подключение к $host:$port")

connect()                           // localhost:8080
connect("example.com")             // example.com:8080
connect(port = 9090)               // localhost:9090
```

Именованные аргументы позволяют пропускать некоторые позиционные параметры с умолчаниями, изменяя порядок.

### Комментарии и документация

#### Однострочные (`//`) и многострочные (`/* */`)
```scala
// однострочный комментарий

/*
  Многострочный
  комментарий
*/
```
Многострочные комментарии могут быть вложенными (начиная с Scala 2.12), что удобно для комментирования блоков кода, содержащих документацию.

#### Scaladoc-комментарии
Используются `/** ... */` непосредственно перед определением класса, метода, трейта. Поддерживают Markdown-подобный синтаксис (в Scala 3 — Markdown; в Scala 2 — собственный вики-стиль, но с опциями поддержки Markdown). 

Пример в Scala 3:
```scala
/**
  * Вычисляет площадь круга.
  *
  * @param radius Радиус круга
  * @return Площадь
  */
def circleArea(radius: Double): Double = Math.PI * radius * radius
```
Генерация документации: `sbt doc` (или `scaladoc`).

### Ранние инструменты

#### Чтение ввода с консоли: `scala.io.StdIn`
Объект `StdIn` предоставляет методы для чтения строк и чисел:
```scala
import scala.io.StdIn

print("Введите ваше имя: ")
val name = StdIn.readLine()
println(s"Привет, $name!")

// Чтение числа
val age = StdIn.readInt()
```
Доступны: `readBoolean()`, `readDouble()`, `readFloat()`, `readLong()`, `readByte()`, `readShort()`.  

#### Вывод: `println`, `print`
- `println(...)` — выводит аргумент и переводит строку.
- `print(...)` — выводит без перевода строки.
- Можно выводить несколько аргументов: `println("x = ", x)`.

```scala
println("Сообщение")
print("Продолжение... ")
println("Завершение")
```
